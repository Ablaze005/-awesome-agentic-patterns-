# Contributing to Awesome Agentic Patterns

We welcome contributions from developers of all skill levels.

## Ways to contribute
- Add a new agent pattern  
- Improve an existing example  
- Add diagrams or architecture explanations  
- Fix typos or improve documentation  
- Submit integration templates  

## How to contribute
1. Fork the repo  
2. Create a new branch  
3. Add your pattern or improvement  
4. Submit a PR  

We will review PRs weekly.
